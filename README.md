Nova Assistant 

سلام! این اولین پروژه‌ی جدی‌مه که توی گیت‌هاب می‌ذارم. یه دستیار ساده‌ی خط فرمانی و گرافیکی که با پایتون نوشتم. خودم تازه شروع کردم به یادگیری برنامه‌نویسی، پس اگه جایی کدش مشکل داره یا راه بهتری وجود داره، خوشحال می‌شم بهم بگید. این پروژه رو برای یادگیری ساختم، پس هر کمکی برای بهتر شدنش برام ارزشمنده.
چیکار می‌تونه بکنه؟

    یادداشت‌ها: اضافه کن، حذف کن، ببین.

    لیست کارها (Todo): با وضعیت انجام/انجام نشده.

    یادآوری‌ها: با تاریخ و ساعت، و یادآوری‌های سررسید شده رو چک می‌کنه.

    آب و هوا: شهرت رو بذار، دما و سرعت باد رو می‌گیره.

    جوک و حقیقت: از APIهای رایگان می‌گیره.

    جستجوی وب: با DuckDuckGo (بدون نیاز به API کلید).

    ماشین حساب ساده: چهار عمل اصلی.

    حالت هوشمند: با استفاده از Ollama و مدل qwen2.5:0.5b می‌تونه به صورت مکالمه‌ای پاسخ بده و حتی از ابزارها استفاده کنه (مثلاً آب‌هوا رو بگیره).

    ذخیره و بارگذاری: همه چیز (یادداشت‌ها، لیست کارها، یادآوری‌ها، تاریخچه و ...) توی فایل nova_ai.json ذخیره می‌شه.

    رابط گرافیکی (GUI): یه پنجره‌ی ساده با PySide6 که قشنگ‌تر از خط فرمانه.
    مخزن رو کلون کن:
    ```bash
    git clone https://github.com/SinaPars9/Nova-Assistant.git
    cd Nova-Assistant
    چیزایی که باید نصب باشه

    پایتون 3.8 یا بالاتر

    Ollama نصب و اجرا باشه (برای حالت هوشمند)

    مدل رو با این دستور بگیر:
    bash

    ollama pull qwen2.5:0.5b

    کتابخونه‌های پایتون توی reqierment.txt:
    bash

    pip install -r reqierment.txt

چطور اجرا کنم؟

    خط فرمان:
    bash

    python command.py

    رابط گرافیکی:
    bash

    python gui.py

توی خط فرمان، کافیه دستورات ساده مثل help، weather، add note و ... رو تایپ کنی. اگه smart mode رو فعال کنی، می‌تونی هر چیزی بپرسی و Nova با هوش مصنوعی جواب بده.
یه کم از پشت صحنه

این پروژه از چند ماژول تشکیل شده:

    assistant.py: کلاس اصلی دستیار

    command.py: پردازش دستورات و منطق اصلی

    cmd_commands.py: میکسین‌ها برای کارهای خاص

    gui.py: رابط گرافیکی

    chat.py: ارتباط با Ollama و مدیریت تاریخچه

    todomanager.py و task_reminder.py: مدیریت لیست کارها و یادآوری‌ها

    tools.py: ابزارهایی که مدل هوشمند می‌تونه صدا کنه (آب‌هوا، جوک، جستجو)

    translations.py: ترجمه خودکار و نمایش فارسی

من کجام؟

یه مبتدی خودآموزم که عاشق کد زدنه. این پروژه رو از صفر شروع کردم و توی مسیر یادگیری کلی چیز جدید فهمیدم. هنوز خیلی جاها می‌تونم بهترش کنم، مثلاً:

    مدیریت خطاها بهتر بشه

    کد تمیزتر و ماژولارتر بشه

    سرعت بارگذاری اولیه بیشتر شه

    رابط گرافیکی قشنگ‌تر و کاربردی‌تر بشه

ازت چی می‌خوام؟ 😊

اگه تجربه‌ای داری، خوشحال می‌شم:

    یه نگاه به کد بندازی و بگی کجاها رو اشتباه رفتم.

    پیشنهاد بدی چطور فلان بخش رو بهتر بنویسم.

    اگه باگ یا مشکل خاصی دیدی، توی Issues ثبت کنی.

    یا حتی یه Pull Request بدی که خودت یه بخش رو بهتر کنی.
